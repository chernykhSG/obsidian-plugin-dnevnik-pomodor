# Дневник помодоро — плагин для Obsidian

Помодоро-таймер, встроенный в Obsidian: по завершении каждого помидора
открывается сводка, которая автоматически дописывается в ежедневную заметку,
а статистика собирается по всем записям.

## Возможности

- 🍅 **Таймер работа/перерыв** — панель в боковом меню + индикатор в статус-баре
- 📝 **Автосводка** — после каждого помидора открывается форма «Итог помодоро»
  (каждая строка — пункт списка), блок `## 🍅 HH:MM — HH:MM` дописывается
  в сегодняшнюю ежедневную заметку; заметка создаётся по шаблону, если её нет
- 📝 **Заметки по ходу помидоры** — кнопка «📝 Заметка» пишет такой же блок 🍅
  прямо во время работы; заметки и финальная сводка стыкуются по времени
  без наложений и дыр
- ⏭️ **Пропуск интервала** — единственная кнопка прерывания: перейти
  работа ↔ перерыв без сводки; в перерыве отменяет его и возвращает
  к старту помидоры
- ☕ **Вопрос после перерыва** — «Начать новый помидоро?» с переводом фокуса
  на окно Obsidian (работает и когда Obsidian на другом рабочем столе macOS),
  звуком и системным уведомлением
- ⏳ **Отсрочка вопроса** — «Отложить на N минут»: в статус-баре и панели
  тикает обратный отсчёт, затем вопрос возвращается; отсрочку можно отменить
  или начать работу досрочно
- 🤖 **Автозапуск перерыва** после сохранённой сводки (отключаемо)
- 🔔 **Несколько звуков завершения** — мелодия, динь-дон, сирена и др.
- 📊 **Статистика** — количество помодоров и минут по дням, фильтр по месяцу,
  кнопка в панели таймера
- ⏱️ **Таймер не засыпает в фоне** — тики идут в Web Worker, поэтому завершение
  срабатывает вовремя, даже когда Obsidian свёрнут или перекрыт

## Установка в Obsidian

Плагин не опубликован в каталоге сообщества, поэтому устанавливается вручную.

### Вариант 1 — скачать файлы

1. Скачайте три файла: `main.js`, `manifest.json`, `styles.css`
   (из [Releases](../../releases), если они есть, либо соберите — см. «Разработка»).
2. В вашем хранилище (vault) создайте папку:

   ```
   <путь к vault>/.obsidian/plugins/dnevnik-pomodoro/
   ```

3. Скопируйте туда все три файла.
4. Перезапустите Obsidian (или нажмите «Перезагрузить плагины» в настройках).
5. Откройте **Настройки → Сторонние плагины**, выключите **Ограниченный режим**
   (Restricted mode), найдите в списке **«Дневник помодоро»** и включите его.

### Вариант 2 — git clone

```bash
cd "<путь к vault>/.obsidian/plugins/"
git clone <URL этого репозитория> dnevnik-pomodoro
cd dnevnik-pomodoro
npm install
npm run build   # соберёт main.js (см. примечание про install-скрипт)
```

Затем шаги 4–5 из варианта 1.

## Использование

- Клик по иконке ⏱️ (таймер) на левой ленте — открыть/закрыть панель таймера
- Кнопки на панели: **Старт / Пауза / Продолжить / Пропустить**, а также
  **📝 Заметка** и **📊 Статистика**
- Длительности работы и перерыва задаются на панели (в состоянии «остановлен»)
  или в настройках плагина
- По завершении помидора: звук + уведомление + окно Obsidian выходит на
  передний план + открывается сводка. Пункты вводятся построчно,
  **Cmd/Ctrl+Enter** — сохранить. Начало блока не раньше конца предыдущего
  блока за день, конец — фактическое время записи
- Во время работы можно зафиксировать промежуточный итог кнопкой
  **«📝 Заметка»** — блок 🍅 запишется в заметку сразу, а финальная сводка
  продолжится с конца последней заметки
- «Пропустить» молча меняет режим (работа ↔ перерыв) без сводки и вопросов;
  в перерыве это отменяет перерыв и возвращает к старту помидоры,
  во время работы — прерывает помидору без записи
- По завершении перерыва: звук + фокус на окно + вопрос «Начать новый помидоро?».
  Ответы: **Начать** — запустить работу, **Не сейчас** — остаться остановленным,
  **Отложить на N минут** — отсрочка с обратным отсчётом ⏳ в статус-баре
  и панели; во время отсрочки доступны «Старт» (начать досрочно) и
  «Отменить отсрочку»

### Команды (Cmd/Ctrl+P)

| Команда | Действие |
|---|---|
| Открыть таймер | показать/скрыть панель |
| Зафиксировать заметку | блок 🍅 в заметку сразу (как кнопка на панели) |
| Открыть статистику | статистика по дням |
| Таймер: старт / пауза | управление таймером |

| Настройка | По умолчанию | Описание |
|---|---|---|

## Формат записи

Каждая сводка (финальная или промежуточная) дописывается блоком:

```markdown
## 🍅 09:30 — 10:00

- сделал задачу
- артефакт: [[заметка]]
```

Промежуточные заметки за один помидор стыкуются по времени автоматически:

```markdown
## 🍅 15:00 — 15:12

- промежуточная заметка

## 🍅 15:12 — 15:30

- финальная сводка
```

## Разработка

```bash
npm install
npm run dev    # esbuild watch → main.js с sourcemap
npm test       # unit-тесты (node:test)
npm run build  # tsc + esbuild production + копирование в тестовый vault
```

> **Примечание.** `scripts/install-plugin.mjs` копирует собранные файлы в
> жёстко заданный тестовый vault автора — поменяйте путь в скрипте под себя
> или просто собирайте `node esbuild.config.mjs production`.

Структура: `src/timer.ts` — логика таймера (работает на Web Worker,
`src/worker-timer.ts`), `src/snoozer.ts` — отсрочка вопроса, `src/timer-view.ts` —
панель, `src/capture-modal.ts` — сводка, `src/confirm-modal.ts` — вопрос после
перерыва, `src/daily.ts` — запись в ежедневную заметку, `src/core.ts` —
парсинг/статистика блоков, `src/stats-modal.ts` — статистика.
